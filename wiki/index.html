NowWhat User Guide

Technical documentation for the NowWhat HPC platform.

Welcome to the technical guide for NowWhat, an HPC platform hosted by Department of Statistical Sciences, University of Padua.

Choose How to Access NowWhat

You can work on NowWhat in two ways:

Access methodBest forStart here
NowWhatHub in a web browserJupyterLab, notebooks, RStudio, VS Code, remote desktops, and terminalsNowWhatHub User Guide
SSH and direct SLURM commandsBatch jobs, automation, file management, and advanced cluster workflowsGetting Started

Both methods run computational work through SLURM and use the same persistent filesystems.

Core Operating Rules

  1. Use the login node only for editing, file management, and job submission.
  2. Run every CPU-intensive, memory-intensive, GPU, or long-running workload through SLURM.
  3. Never assume that direct access to compute nodes is permitted outside a running allocation.
  4. Keep your files organized and place large shared datasets in the appropriate storage area.
  5. Start with small test jobs before scaling to full production runs.

Contact the Guardians of NowWhat

Write to nowwhat@stat.unipd.it if you encounter:

  • account or password problems
  • inaccessible nodes or network issues
  • missing software or broken modules
  • unclear storage requirements
  • repeated job failures that are not explained by your logs
