Access

How to reach NowWhat and complete the first login safely.

This page is the canonical reference for network access, SSH login, and first-login password handling.

Connection Endpoint

Use the login node:

  • hostname: nowwhat.stat.unipd.it
  • port: 22

Direct SSH access to compute nodes is not the standard entry path and must not be used as a substitute for SLURM allocations.

Network Requirements

To reach the login node, your machine must be:

  • on the department network
  • or connected through a VPN that provides access to the department network

If SSH fails immediately, verify network reachability before debugging keys, shells, or terminal clients.

If you prefer a graphical client, configure it with:

One client very useful is Termius. For the MacOS users, download the app direcly from the website.

Operational Rules

  • use the login node for access, editing, file management, and job submission
  • submit compute work through SLURM
  • do not share credentials
  • contact nowwhat@stat.unipd.it if credentials fail or access stops working
