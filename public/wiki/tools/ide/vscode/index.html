VS Code

Instructions for using VS Code with NowWhat.

This page describes how to start a Visual Studio Code Remote SSH session on NowWhat.

VS Code Remote SSH runs the VS Code user interface on your local machine while files, terminals, Python sessions, R sessions, and extensions run on the remote host reached through SSH.

On NowWhat, VS Code must run on a compute node allocated by SLURM. Do not start VS Code remote sessions, Python sessions, R sessions, or other interactive workloads on the login node.

Requirements

Before configuring VS Code, make sure that:

  • Visual Studio Code is installed on your local machine
  • the VS Code extension Remote - SSH is installed locally
  • you can reach the NowWhat login node from your network or VPN
  • you can log in from a terminal with SSH
  • your remote home directory has enough free space for the VS Code server files

  • remote.SSH.useLocalServer: disables VS Code's local-server connection mode, which can fail when compute-node ports are reachable only through the login node

After changing these settings, close any open Remote SSH windows before reconnecting.

When Environments Change

NowWhat environments can change over time. Modules, Spack installations, micromamba environments, or versioned paths may be added, removed, renamed, or rebuilt.

If one or more expected environments no longer appear or stop working in VS Code:

  1. rerun the find commands above on the remote server
  2. update python.defaultInterpreterPath, r.rpath.linux, or r.rterm.linux in Workspace Settings
  3. save the JSON file
  4. reload the VS Code remote window
  5. run Python: Select Interpreter or R: Create R Terminal again
